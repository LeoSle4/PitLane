## Specs
S1. RN-14: "Una orden solo se entrega si tiene registrada la conformidad del cliente, con fecha, hora y usuario".
S2. HU-49 Buscar orden lista para entregar (V-49, Jefe): "buscar entre las órdenes en estado Listo para recoger por placa, nombre o DNI del cliente o número de orden". Result shows only that state, with "número, placa, cliente y fecha en que quedaron listas". No match: "No hay órdenes listas con esos datos". Tapping a result opens its detail (HU-26).
S3. HU-50 Ver resumen de trabajos para la entrega (V-50, Jefe): on a Listo para recoger order show "la falla reportada, el técnico que la atendió y cada avance con su tipo (Hallazgo o Trabajo realizado), descripción, fotos y fecha", chronological; a photo opens full screen; "no tiene opciones de edición ni de eliminación".
S4. HU-51 Registrar la conformidad del cliente (V-51, Jefe): button "Registrar conformidad" + confirm → conformidad saved with fecha, hora y usuario, message "Conformidad registrada". Once registered, detail shows its fecha y hora and the button is no longer offered. Other state: "Solo se puede registrar la conformidad de una orden lista para recoger".
S5. HU-52 Registrar observación del cliente (V-52, Jefe): observation (mínimo 10 caracteres) + "lo acordado", button "Guardar", saved with fecha, hora y usuario, message "Observación registrada". Invalid: "Describe la observación con al menos 10 caracteres". Order stays Listo para recoger; observation shows in the order detail (HU-26); observations are kept after the conformidad is registered. Only on a Listo para recoger order.
S6. HU-53 Marcar orden como entregada (V-53, Jefe): button "Marcar como entregado" + confirm → Entregado, in the state history, message "Vehículo entregado". No conformidad: "Registra la conformidad del cliente antes de entregar". Other state: "Solo se puede entregar una orden lista para recoger". Entregada order no longer counts as "en el taller" (vehicle "Sin orden activa", client can delete vehicle/account), disappears from the Jefe panel, stays in the client's history and timeline ending with "Entregado". "no se envía aviso al cliente".
S7. HU-54 Ver constancia de entrega (V-54, Cliente): on an Entregada order the state screen shows "Ver constancia de entrega"; the constancia shows "número de orden, placa, fecha y hora de la entrega, quién la registró y la fecha de su conformidad"; read-only; only the owner client sees it (RN-08); not offered before Entregada.
S8. Conventions of the project apply (Spanish identifiers and comments, view-id prefixes, Toast for messages, layouts per module): see `odd/tasks/pitlane-ui-local.md` "Conventions". Layers live under `arquitectura/` (vista, viewmodel, repositorio + impl, datasource + local); `modelo/` and `util/` stay outside.
S9. Assumption: the Jefe reaches V-49 from the order panel (FragPanelOrdenes); resumen, conformidad, observación and entrega live in the Jefe order detail when the order is Listo para recoger.
